# Мама, дешевле!

> ИИ ищет — мама экономит.

Автоматический Telegram-сервис, который ищет выгодные предложения на детские товары, анализирует цены и публикует лучшие находки в Telegram.

## MVP v0.1

Цель первой версии — построить бесплатный автоматический контур:

`источник → фильтр → AI → пост → Telegram`

### Принципы

- старт без обязательных платных сервисов;
- ИИ не придумывает цены, наличие, рейтинги или ссылки;
- сначала обычные правила отбирают кандидатов, затем AI оценивает качество предложения;
- история цен хранится отдельно от текущей цены;
- публикации защищены от дублей;
- источники подключаются только разрешёнными способами/API/фидами;
- платные сервисы добавляются только после появления аудитории или дохода.

## План

1. Telegram-бот и канал
2. База данных Supabase
3. Первый источник товаров

5. Deal Score
